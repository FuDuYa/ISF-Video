# Ink! Sans Fight — 第四阶段（音乐卡点视频）

成片：`output/ink-sans-phase4.mp4`（1920×1080，60 fps，H.264 + AAC，全曲 2:27）。
战斗画面在 640×480 原生像素上合成，最近邻放大到中间 1440×1080，左右黑边，全程只有黑、白、灰。

## 背景设定

基于“我素系统”“调零”“南省”等人制作的 Ink! Sans Fight：

1. 第一、二阶段：召唤不同 AU 的 Sans 攻击玩家。
2. 第三阶段：Ink Sans 用彩色墨水攻击。
3. **第四阶段（本片）**：画面全部变为黑白灰，Ink Sans 不再召唤，亲自出手。

画面严格按 UT 战斗：只出现战斗框、灵魂、Ink Sans、底部状态栏和四个按钮；
文字只用 UT 战斗字体（CYF 的 uibattlesmall 图集），不使用任何系统字体、字幕或额外 UI。

## 卡点方式

`maidata.txt` 是 Larva 的舞萌谱面，渲染器逐个音符读取（BPM 202，对照音频瞬态校准 −10 ms）：

| 舞萌音符 | 战斗中的攻击 |
| --- | --- |
| 8 个按键位置 | 映射到战斗框内的一圈，角度不变（1 号在 12 点右侧，顺时针） |
| 星星 / 滑条 | 一支画笔沿滑条的形状（`-` `<` `>` `v` `p` `q` `pp` `qq` `s` `z` `w`）在框内画出墨痕；星星出现到开始滑动的一拍就是虚线预警 |
| 长条 (hold) | 对应方向开出墨池，按长条时长喷出墨水光束，瞄准玩家上一刻的位置 |
| 单点 (tap) | 依段落而定：框边刺出的墨刺 / 从顶部落下的墨滴 / 墨弹 / 骨头 |
| 绝赞 (break) | 墨点聚拢后炸成一圈墨滴，屏幕震动、背景闪一下 |

段落安排（小节号 × 1.188 s）：

| 时间 | 内容 |
| --- | --- |
| 0–5.9 s | 开场：四滴墨落下化成 MERCY / ITEM / ACT / FIGHT，墨迹画出战斗框，灵魂出现（沿用之前认可的按钮演出，代码重写） |
| 5.9–7.8 s | 4 3 2 三个音：Ink Sans 从脚、身体到头被墨水“画”出来（闭眼、背后没有画笔） |
| 7.3–10.1 s | Ink Sans 闭眼、不出手，召唤画笔卡着节拍画出矩形，矩形蓄力、镜头推近倾斜 |
| 10.1–10.7 s | 第一串 16 分：睁眼，矩形变成骨头围栏，8 个半边依次刺入，每下反色闪烁、镜头冲击、残影错位；10.69 s 骨头碎裂 |
| 10.7–17.8 s | 框变宽，画笔滑条 + 墨水光束 + 墨弹 |
| 17.8–29.7 s | 16 分密集段：环绕墨刺，最后一笔画满整圈 + 长光束 |
| 30.9–39.2 s | 安静段，Ink Sans 闭眼，宽框里落墨滴、横向光束 |
| 39.2–46.3 s | 环形墨刺连打 |
| 46.3–49.9 s | 唯一一段骨头（少量使用） |
| 57–65.3 s | 第二个安静段，大墨滴慢慢落下 |
| 84.4–89.1 s | Z 字形大笔刷 |
| 93.9 s | 全曲最强的绝赞 |
| 106.9–115.2 s | 高潮连打 |
| 123.6–139.0 s | 终段，139.0 s 收尾大爆发 |
| 140–147 s | 墨迹散去，Ink Sans 收笔闭眼；143.8 s 最后一个音落下一滴墨，画面淡出 |

## 灵魂的走位

`src/plan.py` 不是手调的：它先把每一帧的伤害区域算出来，倒推出“从这里出发还能活到最后”的位置集合，
再按 UT 的移动速度（每帧 2 像素、八方向）选路，尽量待在框中央、离墨水远、按住方向键时保持惯性。
运行两遍：第二遍里的光束、墨弹、墨滴会瞄准第一遍中灵魂所在的位置，所以看起来是 Ink Sans 在追着打。
当前结果是全程无伤（HP 一直是 92）；如果改了攻击导致躲不开，会自动扣血并闪烁 1 秒。

## 运行

```sh
python3 -m pip install -r requirements.txt   # 另需系统 ffmpeg
python3 src/plan.py                 # 规划灵魂走位（约 1.5 分钟），写入 output/plan.npz、output/aim.npy
python3 src/render.py               # 渲染整段视频（约 1.5 分钟）
python3 src/render.py --still 93.9  # 导出某一时刻的 1080p 静帧
python3 src/render.py --sheet 40 50 # 40–50 秒的 16 格联系表
```

改了攻击或段落后要先重跑 `plan.py` 再渲染。

## 文件

- `src/chart.py` 解析 maidata（tap / hold / slide / break / each）。
- `src/choreo.py` 段落表 `SECTIONS`（每段的框大小、单点用哪种攻击、Ink Sans 的头）和音符→攻击的映射。
- `src/attacks.py` 墨刺、画笔、光束、墨滴、墨弹、墨环、骨头。全部是时间的纯函数，以 2 像素颗粒绘制，和 Ink Sans 贴图的像素粗细一致。
- `src/intro.py` 开场的墨水成形和透视镜头。
- `src/scene.py` 合成一帧：Ink Sans（待机只有呼吸起伏）、战斗框、灵魂、状态栏。
- 外部攻击（`attacks.PenVolleys` / `BoneOrbs` / `LodgedSpokes`，第 17–24 小节的所有单点；第 17–18 小节全部从右边来，第 19–20 小节全部从上面来，第 20 小节加入 `HelixBind` 螺旋捆绑；第 21–22 小节镜头推进到矩形内部，`SquareTunnel` 方框隧道（消失点绕中心漂移）加 `GridFill` 九宫格留白，第 22.75 小节拉远揭示矩形，第 23 小节 `CanvasCube` 矩形长出厚度，以固定的 3D 视角（不转）每个 12 分音符飞进一根骨头（谱面三连一组同一方向：左 / 下 / 正前 / 右，瞄准灵魂，先有浅色提示线或圈），第 24 小节的八分音符才开始转、每转一次斩一刀，两条星星在正面斩出 X，break 时炸开；灵魂贴在正面上（走位在正面自己的平面坐标里规划）。螺旋炸碎的碎片画在九宫格和隧道上层（`Attack.z`），飞出画布后变白继续飞。九宫格到立方体期间灵魂和墨保持整个贴图的距离（`plan.HALF_WIDE`），不会出现贴着黑色却不掉血）。剧本里固定的受击写在 `choreo.FORCED_HITS`（螺旋炸碎的碎骨打中灵魂，扣 10 血）。画布从第 21 小节铺开时就把状态栏和按钮一起包进去（纸上的墨字），之后一直在画布里；画面外也接着是同一张纸（`scene.overscan`，镜头可以拍到屏幕边缘以外）。第 25–28.5 小节：立方体炸开把灵魂直接炸到 FIGHT 右边，它按住方向键（8 方向、UT 速度）走上 FIGHT（`choreo.SOUL_SCRIPT`），没有给回合；炸出的一圈墨水活过来快速逼近，围着灵魂转圈并慢慢收紧（`attacks.HuntingInk`），每拍按一次 FIGHT（`choreo.PRESSES`）：按钮闪一下（`scene.press_flash`），一道斩击（`sprite/fight/1-6.png`）落在一滴墨上，被斩中的墨停住不动。星星在每次换方向时先减速到 0 再反向加速回原速，立方体炸开后消失（`backdrop.StarRain`）。第 28 小节之后暂时没有攻击，等下一段的安排。画布化后不再画战斗框边框（`scene.compose_canvas`）：攻击从画布外面来，在外面是白色、看得见它飞过来（这就是预告），一进入画布就变成墨（合成时画布内的贴图会反色），穿入处溅一点浅灰墨，到对面被纸吸掉。
- 墨水斩击（`attacks.InkStroke`）只作为少量点缀混用（只剩第 24.5 小节的两条滑条）。规则：先用同形状的淡墨扫出预告（至少 0.42 秒，命中前闪烁），命中时才是纯黑；画布上只有会伤人的墨是黑色，装饰（溅点、碎片、圆相、入场墨团）一律是浅灰；攻击结束后 0.2 秒内变细淡出，不留残迹。
- `src/actions.py` 预留的大幅度身体动作（跳起下砸）。目前没有安排使用，Ink Sans 按参考视频全程站定、背着画笔；以后某段需要时由 `choreo.add_slams` 安排。
- `src/soak.py` 第 15 小节末战斗框被墨水灌满、湿透、变成画布的动画。
- `src/titlecard.py` 标题卡和三连音里逐词闪切的标题特写。
- `src/fx.py` 镜头（伪 3D 倾斜、推拉、旋转、冲击）和全屏特效（反色、残影、错位、速度线、暗角）。
- `src/cinema.py` 逐段的运镜和特效安排，改某一段的镜头就改这里。
- `src/backdrop.py` 谱面休息段的背景情绪层（干笔刷痕、滑条形状的大笔触、落墨涟漪、纵深墨点）。
- `src/dialogue.py` Ink Sans 的 UT 对话框和台词时间表 `LINES`，逐字打出、无音效。中文用方正少儿简体 `assets/fonts/FZSEJW.TTF`（你本机方正字库安装的字体，商业字体，公开发布视频前请确认授权），16 像素无抗锯齿 1 倍显示；找不到它时退回 `fusion-pixel-12px.ttf`。
- `src/plan.py` 灵魂走位规划；`src/render.py` 渲染和导出。
- `scene.json` 角色位置、名字 FDY、LV 19、HP 92、状态栏和按钮坐标。
- `sprite/`、`Music/`、`maidata.txt`、`assets/fonts/` 为原始素材，未改动。

所有彩色贴图按亮度转灰（红色灵魂 → 灰度 76，HP 条黄/红 → 226/76）。
